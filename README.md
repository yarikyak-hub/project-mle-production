# Проект: Релиз модели в продакшен

## Описание проекта
Цель проекта — вывести модель машинного обучения для оценки стоимости недвижимости в продакшен, обернув её в FastAPI-микросервис. 
Проект включает: 
 - Контейнеризацию с помощью Docker;
 - Настройку системы мониторинга (Prometheus + Grafana);
 - Построение дашборда для отслеживания метрик в реальном времени.

## Используемые технологии
*   **Python 3.10**, **FastAPI**, **Uvicorn**, **Pydantic**
*   **Docker**, **Docker Compose**
*   **Prometheus**, **prometheus_client**, **prometheus_fastapi_instrumentator**
*   **Grafana**
*   **Scikit-learn**, **Pandas**, **Joblib** (для работы с ML-моделью)

## Эндпоинты микросервиса
- `POST /predict` — получение предсказания цены на квартиру (интерактивная документация Swagger UI доступна по адресу `/docs`).
- `GET /metrics` — экспорт сырых метрик в формате Prometheus.
